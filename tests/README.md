# tests/

Playwright/Puppeteer scripts, baselines, and ad-hoc artifacts. Nothing here is
loaded by the live app — these are dev-only.

## Layout

| Folder | Contents |
|---|---|
| `scripts/` | All `.cjs` and `.mjs` test runners (smoke, e2e, regression, retrofit, layout snapshots, etc.). Run with `node tests/scripts/<name>.cjs` from the project root. |
| `screenshots/` | Output PNGs from screenshot tests, plus the per-test `*-shots/` subfolders generated by Puppeteer runs. Safe to delete and regenerate. |
| `logs/` | Captured stdout/stderr from extended runs (`smoke-test-extended.log` etc.). |
| `baselines/` | Pinned JSON baselines used by visual diff tests (e.g., `test-compact-chrome.baseline.json`). Update only when intentionally re-baselining. |
| `audit/` | Manual graphics-audit scripts and their output: `audit-graphics/` (rendered comparison sheets), `audit-graphics-script.cjs` (the runner). |
| `legacy/` | Frozen reference HTML kept for diffing against historical renders. Not used by tests. |
| `dev-pages/` | Standalone HTML test harnesses (`test-modules.html`, `test-skills.html`) — open directly in a browser. |

## Conventions

- **One concern per script.** A script named `test-grade-chips.cjs` should only exercise the grade-chip UI. Cross-cutting smoke goes in `scripts/smoke-*.cjs`.
- **Screenshots land in `screenshots/<test-name>-shots/`** — the script creates the folder if missing. Don't dump loose PNGs at the `screenshots/` root; the test runner should namespace.
- **Tests must clean up after themselves**: kill the dev server, remove temp artifacts. The smoke tests in this repo all do this; new ones should too.
- **Don't run server-starting scripts in parallel** — port 3199 is the default; multiple runners will collide.
