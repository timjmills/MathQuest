    How each number is worked out
    • Live skills: every skill in the app's skill list (retired ones stay listed so share codes keep working).
    • Redesign passed: skills an independent critic scored 8 or more on every criterion, every page type and every screen.
    • Lessons: lessons the app prints, each pinned page by page so an unplanned change is caught.
    • Check tools: the automatic check programs. Proved checks: each one shown to fail on the bad page and pass on the fix. Critic findings turned into checks: rows in the findings ledger, dated by the week the finding came in.
    • White Rose steps: the 872 small steps; covered when a live skill teaches the whole step.
    • Usage: the share of the weekly limit used, typed in each week; marked "about" where it is an estimate.
    • The board is rebuilt each week by node tests/scripts/ws-pace.cjs --write; the deploy check --check fails if a finished week is missing or its numbers differ from the project history.
