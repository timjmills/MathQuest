# MAP Growth builds audit (2026-10-10)

The brief is `MAP-BRIEF.md`. The data is `data/curriculum/links/MAP.json`, made by merging the three strand-group parts in
`map-parts/` (`A` Number & place value + Operations & algebra, `B` Multiplication & division + Fractions & decimals,
`C` Measurement + Geometry + Data & graphing) with `map-parts/merge.cjs`. The merge checks every skill key is live, every row
that is not exists-ok has a proposal, and every proposal is used. A reused proposal is copied verbatim from its source list
(`WRM_PROPOSALS`, `STANDARD_PROPOSALS`, `WRM_EXTENSIONS`, `VISUAL_BUILDS`) and only gains the `map` facet. This report is
generated by `map-parts/report.cjs`.

**How a status was decided.** Every status comes from generated items (`tests/scripts/ws-sample-items.cjs`, seeded, n = 20,
or `--dist 200` for "does it ever deal X"), never from a skill's name. The note on each row says what was sampled.
`exists-ok`: a skill deals the task in a form at least as demanding as MAP's. `exists-regrade`: it deals it, but the skill
still has to pass the 8/10 re-grade, or the answer form is weaker than MAP's; the row's proposal is the residual gap, if any.
`partial` / `missing`: the proposal names what closes it.

**Evidence.** Each row's `evidence` cites public NWEA material: the MAP Growth RIT Reference Charts (sample items by RIT band,
both the NWEA CDN copy and a district copy), the NWEA DesCartes learning-continuum statements by band (2014 files M2_NO,
M2_OAT, M6_OAT … served by Bismarck Public Schools), and the NWEA item-pool blog on technology-enhanced items. NWEA's own
concept PDFs on teach.mapnwea.org returned 503 during the audit, so they are not cited. Nothing was copied into the repo.
RIT bands are those the evidence gives where it gives one; otherwise the band of the skill's RIT list in `data.js`, or an
estimate (flagged in the note).
