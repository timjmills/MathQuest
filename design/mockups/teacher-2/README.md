# Teacher site 2.0 — T1 clickable mock-up (board C)

Open `index.html` (served: `python3 -m http.server` from the repo root, then `/design/mockups/teacher-2/`; `npx serve` drops the query string when it redirects `app.html` → `/app`, so `?tray=` links open empty there; file:// also works).

| File | What |
|---|---|
| `app.html` + `app.js`, `app.css`, `thumbs.js` | The clickable mock-up. `?theme=dark|light`, `?tray=demo1|demo3|demo3x|lesson|<cat:skill,...>`, `?ctab=board|quizzes|map|progress`, `?confirm=<set>`, `#skills #lessons #classes #print #quiz #buildfrom #share #quizshare #chip/<cat:skill> #board #lessonprint #lessonpanel #profile #trayopen`, `?walk=<flow id>` |
| `thumbs.js`, `thumbs-check.cjs`, `thumbs.html` | The skill thumbnails, picked by category + skill id; `node thumbs-check.cjs` holds all 715 live skills to their names (fix round 1); `thumbs.html` shows them all |
| `tokens.css` | The only raw values: type, spacing, radii, shadows, neutrals and board C (checked by `tests/scripts/ws-teacher-tokens.cjs`) |
| `flows.js` | The §2.6 flows as click lists (flows page, walk-through, shoot) |
| `data.js` | GENERATED by `node make-data.mjs` from the live skills, each skill's own options (`skill-options.js`, read-only) and presets, standards, White Rose steps and MAP tasks |
| `files.html` | GENERATED by `node make-files.cjs` (git fetch master and wip-teacher-ui first) |
| `shoot.cjs` | Every screen checked at 1366, 1280, 1024, 820 and 390 (no sideways scroll, nothing clipped in a panel, nothing hidden in a sideways strip, one primary above the fold at 1366); PNGs at 1366 × 768 and 390 × 844, light and dark, plus the layouts that change at 1280 / 1024 / 820 → `shots/`; every flow clicked → `flows-check.js`; writes `index.html`. `--boards` redraws `board-a.png` / `board-b.png` |
| `palette.html`, `colour.js`, `palette/board-c-search.py` | Board C swatches, colour-blind simulation, where each colour moved; the search that found board C |
