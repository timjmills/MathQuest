# Teacher site 2.0 — T1 clickable mock-up (board C)

Open `index.html` (served: `npx serve .` from the repo root, then `/design/mockups/teacher-2/`; file:// also works).

| File | What |
|---|---|
| `app.html` + `app.js`, `app.css`, `thumbs.js` | The clickable mock-up. `?theme=dark|light`, `?tray=demo1|demo3|demo3x|lesson|<cat:skill,...>`, `#skills #lessons #classes #print #quiz #buildfrom #share #quizshare #chip/<cat:skill> #board #lessonprint #lessonpanel #profile #trayopen`, `?walk=<flow id>` |
| `tokens.css` | The only raw values: type, spacing, radii, shadows, neutrals and board C (checked by `tests/scripts/ws-teacher-tokens.cjs`) |
| `flows.js` | The §2.6 flows as click lists (flows page, walk-through, shoot) |
| `data.js` | GENERATED by `node make-data.mjs` from the live skills, standards, White Rose steps and MAP tasks |
| `files.html` | GENERATED by `node make-files.cjs` (git fetch master and wip-teacher-ui first) |
| `shoot.cjs` | Every screen at 1366 × 768 and 390 × 844, light and dark → `shots/`; screen checks; every flow clicked → `flows-check.js`; writes `index.html`. `--boards` redraws `board-a.png` / `board-b.png` |
| `palette.html`, `colour.js`, `palette/board-c-search.py` | Board C swatches, colour-blind simulation, where each colour moved; the search that found board C |
