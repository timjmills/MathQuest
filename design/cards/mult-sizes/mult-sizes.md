## 6. Misconceptions

For answer keys, `wrongAnswer`, error analysis, True or False? and Reason It (P-TH-13).

- **M-S1** drops the zeros of a place-value part — e.g. 7 x 3,000 written 21 in the area box; 30 x 20 = 60
- **M-S2** forgets the last carry, so the new top place is missing — e.g. 3,456 x 7 = 4,192 (for 24,192)
- **M-S3** multiplies only tens x tens and ones x ones — e.g. 34 x 26 = 600 + 24 = 624
- **M-S4** leaves out the placeholder zero in the second row — e.g. 215 x 36: second row 645 under 1,290 -> 1,935 (for 7,740)
- **M-S5** treats a zero digit as 1 or skips its part — e.g. 3,045 x 6 = 18,276 (for 18,270)
