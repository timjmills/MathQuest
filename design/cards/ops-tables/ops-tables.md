# Spec card: Times tables beyond the fact drill: the multiplication chart, properties, arrays and equal groups, and the plain × / ÷ stories (pilot unit G3-Y4.B4)

Family card for the pilot unit's multiplication skills that are not the fact drill. mult_chart: a black-and-white 12 x 12 (or 10 x 10) chart, one product looked up or a few cells filled (never the factor pairs printed in the prompt). mult_properties: the order property drawn as an array and the same array turned, identity (x 1) and zero (x 0) facts, and the distributive split. arrays_groups: an array or ringed equal groups, '__ rows of __ (groups of __). __ in all.' (three slots, one frame every item). The plain stories: one x or ÷ story per cell with no picture row, answered with a number and its unit. Paper, key and the three screen hosts are one drawing.

## 2. Problem types and progression

*From repo sources: design/catalogue/mult-div-integers.md (verdicts, MU-A2/A3/A7/A27/A28, MU-M1..M7), the passed detailed lessons 3a (g3-oa5-mult-properties) and 4 (g3-oa9-mult-table-patterns) and their RESEARCH.md, PROBLEM_TYPES MU rows. Reference grammar (MathWorksheets4Kids 'multiplication chart: find the missing', 'properties of multiplication', 'arrays: write the multiplication sentence'; IXL 3rd grade 'multiplication tables up to 12: find the missing factor', 'properties of multiplication', 'write multiplication sentences for arrays'): ours keeps one product or one property per boxed cell, black and white, big digits.*

**Problem types**

- mult_chart look-up: a black-and-white chart with one row and one column shaded to a cell; write the product (the factor pair is the row and column headers, never printed in the prompt)
- mult_chart fill: a chart (or a window of it) with a few cells blank; write each product
- mult_properties order: an array and the same array turned; write both facts (task both), the turned fact from a known one (known), or the facts alone (missing)
- mult_properties identity / zero: 'n x 1 = [ ]', '0 x n = [ ]', with counters or none
- mult_properties distributive: an array split into two parts; '__ x __ = (__ x __) + (__ x __)'
- arrays_groups: an array (rows of) or ringed equal groups (groups of); three slots: __ rows of __, __ in all
- plain stories: one x or ÷ story (equal groups, arrays, sharing, grouping), no pictures, a number and its unit

**Progression** (one new thing per step, P-1)

1. arrays / equal groups to 5 x 5 with pictures (2.OA.4, 3.OA.1) -> the order property on turned arrays -> facts alone (pictures off)
2. identity and zero with counters -> without (S11); divide by 1 and by itself (S12, div_by_itself)
3. chart look-up of one product -> fill a few cells -> find patterns (S6, lesson 4)
4. stories with pictures (mult_word_problems) -> plain (the _plain skills), one change a step (P-1)

## 6. Misconceptions

For answer keys, `wrongAnswer`, error analysis, True or False? and Reason It (P-TH-13).

- **MU-M1** counts the rows (or groups) as the total — e.g. 3 rows of 4: 3 in all
- **MU-M2** reads one row or column too far on the chart — e.g. 6 x 7 read as 6 x 8 = 48
- **MU-M3** thinks turning the array changes the product — e.g. 3 x 5 = 15 but 5 x 3 = 53
- **MU-M4** x 0 gives the other number (zero is 'nothing happens') — e.g. 7 x 0 = 7
- **MU-M5** x 1 adds one — e.g. 6 x 1 = 7
- **MU-M7** splits the wrong factor or drops a part in the distributive split — e.g. 6 x 7 = (6 x 5) + 2
