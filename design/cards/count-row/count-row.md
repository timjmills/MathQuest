# Spec card: Skip counting on the count row (`count-row`): count by 1-12 and any step, the number-line row and the grid row

Generated by `node tests/scripts/ws-spec-card.mjs --template count-row` from `design/cards/count-row/card.json` and the repo. Do not edit by hand: edit card.json and regenerate. Builders read this card; critics keep reading the full standards and RUBRIC.

Template card for the skip-count row. One row per count: the step in a boxed tab at the left, hop arcs over the numbers, given numbers plain, every missing number an empty writing box in its own place (SL-11). count_by_tables deals the tables 1-12 (or the teacher's own rows: any step, start and direction) as two lines of 6; skip_count_line draws the same row on a ruled number line with a tick under every number; skip_count_grid deals the 2s / 5s / 10s count on a hundred-square strip. Key = the same row with every box written in. Paper, key and the three screen hosts are one drawing.

## 1. What it teaches

Count by a step (1.NBT.A.1 count to 120; 2.NBT.A.2 count by 5s, 10s and 100s within 1,000; 3.OA.C.7 know the multiples as the table's count; 4.OA.B.4 multiples). WRM Y2.B1.S15 (2s, 5s, 10s), Y2.B1.S16 (3s), Y4.B4 S1-S10 (multiples of 3, 6, 9, 7, 11, 12). A count row is a structure the pupil fills from left to right; the first two printed numbers show the step.

## 2. Problem types and progression

*From repo sources: design/status/skip-count.md (critic r1-r5 rounds, SC1-SC6, small-fixes G1-G6), WORKSHEET_DESIGN_STANDARD TY-10 / TY-10b (the count row, the one-line swipe ruling), PROBLEM_TYPES count rows, design/catalogue/mult-div-integers.md. Reference grammar (MathWorksheets4Kids skip-counting strips and 'fill in the missing multiples', IXL 'skip-count by 3s' number-line hops, K5 Learning count-by rows): a row of 10-12 numbers with blanks; ours keeps 12 numbers in two lines of 6, one box per missing number, never a line under the row.*

**Problem types**

- count row (arcs look): the step tab, the first two numbers printed, the rest blank or half blank; write the missing multiples - the core item
- count row with a start that is not the step (by 5 from 3: 3, 8, 13 ...) or counting back towards 0 (teacher's own rows)
- count row with the times label under each number (option `times`: '1 x 4' ...), a hint that fades (drawn at levels 1 and 3, grey at 2, dropped on tests)
- number-line row (skip_count_line): the same hops above a ruled line, a tick per number, each missing number a box under its tick
- grid row (skip_count_grid): the 2s / 5s / 10s count on a hundred-square strip, the missing squares boxed

**Progression** (one new thing per step, P-1)

1. count by 2, 5, 10 from 0 (Y2 / grade 1) -> count by 3 -> the tables 4, 6, 7, 8, 9, 11, 12 (Y4 / grade 3), one table a step (P-1)
2. first two numbers printed (shows the step) -> first one only -> half blank (fill)
3. times labels on (a hint) -> off; tests never draw them (P-7)
4. count on -> count back towards 0 -> a start that is not the step

## 6. Misconceptions

For answer keys, `wrongAnswer`, error analysis, True or False? and Reason It (P-TH-13).

- **M-C1** adds 1 instead of the step after a printed pair (counts on in ones) — e.g. 3, 6, 7, 8
- **M-C2** loses the step across a ten (bridging) — e.g. 7, 14, 21, 28, 34
- **M-C3** counting back: adds instead of taking away — e.g. 60, 55, 60, 65
- **M-C4** a start that is not the step: counts the multiples of the step from 0 instead — e.g. by 5 from 3: 3, 5, 10, 15
