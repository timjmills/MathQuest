## 6. Misconceptions

For answer keys, `wrongAnswer`, error analysis, True or False? and Reason It (P-TH-13).

- **M-N1** odd x odd is even (the adding rule carried over) — e.g. 5 x 7: Even
- **M-N2** decides by the first factor only — e.g. 3 x 4: Odd
- **M-N3** a pattern seen in the first numbers is taken to hold for all — e.g. 5, 10, 15: every number is odd
- **M-N4** a sentence that fits some products is called true — e.g. every product in the 5 times-table ends in 5: True
- **M-G1** the next term has one more, whatever the step — e.g. 3, 5, 7 -> 8
- **M-G2** doubles the last term — e.g. 3, 5, 7 -> 14
- **M-G3** reads the rule across two terms — e.g. 1, 3, 5: rule + 4
- **M-G4** Term 10 = 10 x the step, the start forgotten — e.g. 1, 4, 7: Term 10 = 30
