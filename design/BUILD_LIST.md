## Build order

1. Each lane builds its new templates first (they unblock entries in other lanes: `bar-model`, `graph-axes`,
   `shape-grid`, `coord-grid` are the most shared).
2. Inside a lane, entries in the order below: dependencies first (`after`), then highest impact first
   (standards closed × 2 + White Rose steps closed + the small steps whose pages use the representations it draws).
   The frozen lanes (`k2`, `operations`) keep their original order; their entries added from the visual
   catalogue follow, in dependency-then-reach order.
3. Lanes run in parallel; an entry whose dependency is in another lane waits for it (named in its `After` line).

### 1. Sort into Groups — `sort_groups`

- **What:** new skill `comparing:sort_into_groups`. Grade PK-K · family counting · source White Rose audit.
- **Closes (standards):** K.MD.B.3, M.EE.K.MD.1, M.EE.K.MD.2, M.EE.K.MD.3, M.EE.1.MD.4 · tag with CCSS K.MD.B.3, EE M.EE.K.MD.3, M.EE.K.MD.1, M.EE.K.MD.2, M.EE.1.MD.4
- **Closes (White Rose steps):** R.B1.S4, R.B1.S5, R.B1.S6, Y1.B1.S1
- **Teaches:** sorting objects by one attribute (kind, colour, size, shape) into labelled groups, then saying the sorting rule.
- **Extended for the standards:** count each group, say which has most / fewest and order the groups by count; attributes big/small, heavy/light.
- **Problem types:** (1) sort by a given rule; (2) find the rule of a sort; (3) count each group and say which has most; (4) order the groups by count; (5) sort by big/small or heavy/light.
- **Representation:** picture tiles and two or three labelled sorting rings; write the letter of each tile in its ring; option: rule given or rule found. Templates: `wordpic`, `counters`; new: `sort-rings`, `picture-row`.
- **Answer:** write each tile letter in its ring; write how many in each group.
- **Ladder:** O2 2 groups → 3 groups → rule found by the pupil → order the groups · O3 first tile placed, labels with pictures → words only · O6 rings / Carroll boxes.
- **Misconceptions:** sorts by two attributes at once; leaves tiles unsorted; counts a tile in two rings.
