# MAP #1 (owner's note, Todoist task "MAP #1", 2026-09-28)

The MAP word problem is better described as a **two-step change problem** where the quantity changes **twice**:

**start amount → get more or get less → get more or get less again → final amount**

So students should practise all four possibilities:

- **add, then add**
- **add, then subtract**
- **subtract, then add**
- **subtract, then subtract**
